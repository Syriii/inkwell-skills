# 文风采集模板

按以下 9 段结构提取和分析文风。**每段必须包含从原文中统计出的具体数据，不允许只写印象式描述。**

---

## 1. 核心定位

**提取目标**：用一句话定义这个人格。读者读完后的感受是什么？这决定了全文的语气基线。

**提取方法**：
- 读完全部样本后，问自己：这些文章的共同"语气温度"是什么？
- 不是描述文章内容，是描述**说话人和读者的关系**——老师对学生？朋友对朋友？专家对同行？冷眼旁观者对世界？
- 给这个人格一个**一句话标签**（如"穿白大褂的朋友"），后面所有章节都围绕这个标签展开

**输出**：
- 人格标签（一句话）
- 与读者的距离（面对面聊天 / 台上讲给台下 / 同行交流 / 冷眼旁观）
- 读完后的感受（"原来如此，以后知道怎么做了" / "这个人懂好多" / "说得太对了我也有同感" / "这个世界真有意思"）

**示例**（健康科普）：
- 人格标签："穿白大褂的朋友"
- 距离：面对面聊天，不是站在讲台上讲课
- 读者感受："原来如此，那我以后就知道怎么做了"，不是"这个人懂好多"

---

## 2. 开头模式

**提取目标**：这个风格用什么样的开头把读者拉进来？开头决定读者是否继续读。

**提取方法**：
- 逐个分析所有样本的开头 50-150 字
- 归类：场景引入 / 直接引语 / 反常识翻转 / 数据冲击 / 提问 / 故事 / 其他
- 统计每种开头的使用频率
- 标记哪些样本的开头最有效（读者最想继续读），分析为什么

**输出**：
- 有效的开头技巧（2-4 种），每种配原文实例
- 错误示范（该风格下不应使用的开头方式）
- 正反例对比表

**注意**：同一体裁下不同人格的开头可能完全不同。注意区分。

---

## 3. 段落节奏

**提取目标**：这个风格下，段落是怎么呼吸的？段落长度分布和切换模式直接影响阅读的轻松感。

**提取方法**：
- **必须做统计**：数每个样本段落的句子数，算出 1-2 句段 / 3-4 句段 / 5+ 句段的比例
- 观察单句成段的用途：画面定格？认知翻转？情绪重音？还是懒？
- 观察段落之间有没有连接词（"此外""不仅如此""另一方面"）——有的话记录用法，没有的话记录"无连接词"
- 观察文章切分的频率：多少字换小标题？多少字空行一次？

**输出**：
- 段落句数分布数据（百分比）
- 单句成段的功能说明
- 节奏模式图（如：短（定调）→ 中（展开）→ 短（收束）→ 换气 → 下一拍）
- 段落间衔接方式（连接词 / 逻辑自然衔接 / 混合）

**示例**（健康科普）：
- 1-2 句段：超过一半的段落
- 单句成段用于画面定格、认知翻转、情绪重音
- 段落间无连接词，靠逻辑自然衔接

---

## 4. 标点符号

**提取目标**：每种标点的使用频率和功能分配。标点是文风的骨架——不同的标点策略可以制造完全不同的阅读节奏。

**提取方法**：
- 对每个标点（逗号、句号、破折号、省略号、感叹号、引号、括号），分别统计：
  - **频率**：全文的总体使用量（高 / 中 / 低 / 几乎不用）
  - **功能**：在这个风格里这个标点承担什么角色
  - **位置偏好**：用在句首？句中？句末？
- 特别注意：
  - 逗号密度——决定句子的"气口"长度
  - 分号频率——几乎不用分号的风格 vs 高频使用分号的风格是两种完全不同的节奏
  - 感叹号克制程度——全篇只用 3-5 处 vs 每段都在感叹
  - 破折号的用法——制造停顿？解释说明？翻转？多种功能并存？

**输出**：
- 每种标点的频率级别和功能说明
- 典型例句（展示该风格下此标点的标准用法）
- 特别注意：此风格下**绝对不能**用的标点方式

**示例**（健康科普-逗号）：
- 高频使用，长句用逗号切成 5-12 字的短分句，模拟说话的气口
- 逗号代替顿号做列举：「油炸的、烧烤的、高糖的东西」而非「油炸、烧烤、高糖食物」

---

## 5. 人称用法

**提取目标**："你""我""我们"各自的出现频率和使用模式。人称决定了读者在文章中是什么位置。

**提取方法**：
- **逐样本统计**"你""我""我们"的出现次数，算出每 500 字的频率
- 观察不同人称出现的位置规律：
  - "你"：开头就用还是中间才出现？建议句中密集还是叙事句中出现？
  - "我"：出现吗？出现时是分享个人经历还是表达个人观点？
  - "我们"：出现吗？用来拉近关系（"我们都会遇到"）还是用来代表权威（"我们建议"）？
- 观察不同来源之间的差异——同一体裁同一人格下，"你"字频率在不同来源之间可能差 2-3 倍

**输出**：
- "你"的每 500 字频率范围和位置规律
- "我"的使用模式（不出现 / 偶尔分享经历 / 频繁表达观点）
- "我们"的使用模式（不出现 / 拉近距离 / 代表权威）
- 不同来源间的差异（如有）

**示例**（健康科普）：
- 丁香医生："你"每 500 字 8-15 次，开头即用，建议句中密集
- 果壳："你"每 500 字 2-5 次，频率显著低
- "我"偶尔出现，用于分享个人经历而非表达观点

---

## 6. 口语策略

**提取目标**：这个风格用什么方式让文字像人说的话而非机器生成的？口语策略决定了文章的亲切感。

**提取方法**：
- 在样本中标注所有"不像书面语"的表达，归类：
  - 口语连接词（"说实话""说白了""你想想""对，就是这样"）
  - 生活化动词（"搞""弄""管用""靠谱""翻车"）
  - 日常类比（把抽象概念转化为生活场景的比喻）
  - 直接引语（还原真实对话场景的引用）
  - 网络化轻表达（"离谱吧""崩了"——适度使用）
- 同时标注**该避免的口语**：
  - 过度网络化的短期流行语（"绝绝子""yyds"）
  - 带货主播式称呼（"家人们""姐妹们"）
  - 放弃解释的偷懒表达（"懂的都懂"）
- 注意：避免清单可能随风格完全不同。某个风格下"懂的都懂"可能完全不会出现，不需要列

**输出**：
- 高频口语策略表（类型 + 实例 + 用途）
- 该避免的口语列表（仅限此风格下实际可能踩的坑）

---

## 7. 数据呈现

**提取目标**：这个风格怎么处理和呈现数字？数据的包装方式直接决定文章是"人的话"还是"论文翻译"。

**提取方法**：
- 标注样本中所有包含数字/数据的地方
- 分析每个数据的呈现方式：
  - 裸数字（直接给出，不翻译）→ 数有多少处
  - 数字 + 人话翻译（"90% 的东亚人——喝了严重腹泻"）→ 数有多少处
  - 精确数字制造冲击（"37 例"而非"很少"）
  - 大数字找对照物（"20 万，相当于一台家用轿车"）
  - 数字串成因果链（从 A 到 B 到 C）
- 统计裸数字 vs 包装数字的比例——这是关键指标

**输出**：
- 数据呈现的核心原则（一句话）
- 具体手法列表（每种配原文实例）
- 裸数字 vs 包装数字的比例
- 正反例对比

**示例**（健康科普）：
- 核心原则：数字不裸奔。每个数据后面跟一句人话。
- 手法：精确数字制造冲击、百分比翻译成比例、大数字找对照物
- 裸数字几乎不存在

---

## 8. 结尾模式

**提取目标**：这个风格怎么结束一篇文章？结尾决定了读者最后带走什么。

**提取方法**：
- 逐个分析所有样本的结尾 50-150 字
- 归类：回扣开头 / 行动建议 / 一句话定论 / 开放式提问 / 总结要点 / 情感升华 / 戛然而止 / 其他
- 标记哪些不该用：
  - 总结全文要点（"综上所述""总而言之"）
  - 参考文献式收尾
  - "希望通过这篇文章让大家了解……"
  - 模板化的升华（"让我们一起期待更美好的明天"）

**输出**：
- 有效的收尾方式（2-3 种），每种配原文实例
- 明确列出的不该用收尾（仅限此风格下会犯的）

**示例**（健康科普-回扣开头）：
- 开头："西瓜寒，少吃""羊肉热，多吃"
- 结尾："下次再有人对你念'这个寒别吃'——你知道是怎么回事了。"

## 9. 风格特有禁忌

**提取目标**：这个风格下做了就会被读者识别为"不对劲"的事。注意与通用 AI 味区分——这些是此风格特有的，换一个风格可能完全 OK。

**提取方法**：
- 回顾所有样本，问：如果一篇文章自称是这个风格但做了 X，读者会皱眉头？
- 这些禁忌必须**能从样本中反向验证**——所有样本都不做 X
- 与通用 AI 味（见 SKILL.md 审查流程）区分：
  - 通用 AI 味：自问自答、结构预告、编号列举、收束冲动、书面语残留、节奏机械——不管什么风格出现这些都会像机器写的
  - 风格特有禁忌（写在本段）：本风格下的红线，但换个风格可能完全 OK

**关键：不只说"不要做 X"，必须给出"本风格怎么做 Y"。** 只告诉 Claude 禁止做什么是不够的——它需要知道这个风格下**用什么来代替**。

**输出**：
- 禁忌清单（每条配说明 + 本风格下的正面替代方式）
- 每条配"如果犯了会怎样"——帮 Claude 理解后果

**示例**（健康科普）：

| 禁忌 | 为什么 | 正面替代 |
|------|--------|---------|
| 感叹号全文超过 5 处 | 医生朋友在喊叫，失去信任感 | 用句号收束。内容本身的力量不需要标点加码 |
| 以参考文献式收尾 | 这是公众号，不是百科词条 | 回扣开头场景，或给一句读者能记住的话 |
| 学术术语不翻译 | 说"白细胞介素-6"读者就走了 | 说"炎症因子"或"让你发炎的东西" |
| 破折号制造戏剧停顿 | "不是成分分析——是效应分类。"这种"——制造强调"的句式健康科普里几乎不用 | 分两句，或用"说白了""就是说"过渡 |
| 引号包裹大白话 | "怎么吃之后，身体会怎么反应"加引号像在定义术语 | 去掉引号直接说。不是什么概念，就是一句解释

## 采集流程

1. **收集样本**：按默认标准（12+ 篇，3-4 来源，每来源 5+ 篇），达不到时报告缺口、降级需用户确认
2. **逐篇拆解**：每篇标注 9 段对应的特征
3. **交叉对比**：不同来源之间找共性（应该是核心人格）和差异（应该是子变体）
4. **输出风格文件**：按上述 9 段结构写入 `references/styles/{style-name}.md`
5. **验证**：用该风格写一段 200-300 字的独立内容（非任何原文的话题），对照原文检查是否像

```markdown

**适用**：{suitable_for 列表}
```
