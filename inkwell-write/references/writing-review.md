# 写作审查与逻辑链

仅在创作模式的提纲、草稿和定稿阶段读取。执行检查并修复后，再向用户呈现产物。

## 提纲审查

逐项检查：

1. **结构类型明确**：递进式要求段段因果相连；并列式要求共享前提、各论点独立闭合，不给并列论点编造递进关系。
2. **顺序自然**：递进式按读者问题出现的顺序；并列式按读者关心程度排序。
3. **段段有目的**：递进段承担破、转、用等角色；并列论点各自形成“起点问题→解释→落脚点”。
4. **逻辑闭合**：开头问题在结尾得到回答；并列式还要确认共享前提成立。
5. **字数适配**：预估字数匹配目标平台和用户要求。
6. **无关键遗漏**：讨论中的核心论据都在提纲中有位置。

## 逻辑链推导

提纲确认后、出草稿前必须推导逻辑链并让用户确认。

### 递进式

每个段落回应上一个问题，并自然引出下一个问题：

```text
[开头场景]
  ↓ 读者自然产生的第一个问题
[段落 A] 回应并引出新问题
  ↓
[段落 B] 回应并继续推进
  ↓
[实际场景] 读者知道何时使用这些知识
  ↓
[收尾] 回到开头并完成回答
```

检查每个箭头：左侧内容是否真的会让读者产生右侧疑问。无法放进链条的段落应删除或重新定位。

### 并列式

先建立共享前提，再让各论点独立闭合：

```text
[开头场景]
  ↓
[共享前提]

论点 1：前提 → 起点问题 → 解释 → 落脚点
论点 2：前提 → 起点问题 → 解释 → 落脚点
论点 3：前提 → 起点问题 → 解释 → 落脚点

[收尾] 综合论点，回到实际场景
```

论点之间用自然过渡，不使用“所以”“然后”等词伪造因果。排序遵循读者关心程度，而非虚构的推导顺序。

## 写前自检

先问：是在传递信息，还是在表演“写一篇好文章”？发现以下迹象就改回直接表达：

- 预告结构：“接下来讲三点”“首先要说”。
- 虚构发现过程：“查了才知道”“说实话一直没当回事”。
- 戏剧性转折：用独立短句制造并不存在的悬念。
- 追求金句：三连排比、破折号收束、为摘抄而写。
- 替读者总结：“你会发现”“这说明”。

## 草稿审查

### 结构

- 开头 50–100 字给出继续阅读的理由。
- 每个论点有例子、细节或数据支撑。
- 全文语气一致，结尾回扣开头。
- 删除不服务论点的素材展示。

### AI 味表层扫描

1. **自我解释**：自问自答、结构预告、铺垫句、假发现过程。
2. **编号化思维**：不必要的“三个维度”“两种情况”。
3. **收束冲动**：段末总结、空泛金句、凭空上价值。
4. **书面语残留**：机械连接词、介词框架、术语错位。
5. **节奏机械**：段落等长、破折号表演、引号包裹大白话、无意义单句段。

### 深层自问

1. 这句话日常真的会说吗？
2. 文中是否保留了真实的困惑、好奇和必要停顿？
3. 是否在替读者下判断？
4. 下一句是不是上一句自然需要的内容？特别检查“也、还、另外、但、所以、然后”。
5. 单句段落是否承担真正的翻转或实践转向？每篇控制在 3–4 处内。

### 审查顺序

1. 标记直接引语、数据、术语和关键事实句为保护区，只检查准确性。
2. 扫描并修复五类表层模式。
3. 对照选定风格文件 §10 检查风格特有禁忌。
4. 用五个深层问题通读全文。
5. 回读两遍：第一遍检查信息保真和断裂；第二遍清理表演句、收束腔和旁白腔。

## 定稿检查

- 标题准确，无标题党。
- 手机阅读段落不过长，小标题层级清楚。
- frontmatter 完整，正文无残缺。
- 外部引用标注来源，待查证项没有伪装成事实。
