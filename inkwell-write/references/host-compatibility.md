# 宿主兼容说明

只在外部检索、网页读取或跨任务执行时读取本文件。讨论、提纲、草稿和归档格式不因宿主变化。

## 路径解析

- `<skill-dir>`：当前 `inkwell-write/SKILL.md` 的父目录。
- `<project-root>`：包含 `discussions/`、`creations/` 的内容项目根。
- `<search-skill-dir>`：由宿主技能发现机制定位到的 `inkwell-search` 目录。

## 能力映射

| 所需能力 | Claude Code | Codex | 无该能力时 |
|---|---|---|---|
| 本地素材搜索 | 调用 `<search-skill-dir>` 脚本 | 调用同一脚本 | 使用文件名、frontmatter 和全文文本检索 |
| 外部网页研究 | 使用已配置的搜索、抓取或浏览器能力 | 使用可用的 web、in-app browser 或连接器 | 让用户提供来源；明确标记待查证项 |
| 图片理解 | 使用当前会话视觉能力 | 使用当前会话视觉能力 | 请求 OCR、文字说明或跳过图片结论 |
| 并行研究 | 宿主允许时委派独立任务 | 当前策略允许时使用多代理 | 在主会话顺序执行 |

不要在文章中暴露工具名或宿主差异。宿主增强失败时回退到核心写作流程，不得伪造来源、搜索结果或事实核验。
