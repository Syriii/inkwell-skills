# 宿主兼容说明

只在使用视觉、已登录浏览器或委派代理时读取本文件。核心采集流程始终优先运行技能自带脚本。

## 路径解析

- `<skill-dir>`：当前 `inkwell-capture/SKILL.md` 的父目录。
- `<project-root>`：包含 `.web-analysis.yaml` 或内容目录的当前项目根。
- `<search-skill-dir>`：由宿主技能发现机制定位到的 `inkwell-search` 目录。
- 不要把 `.claude/skills`、`.codex/skills`、用户名或机器绝对路径写进归档、命令模板或脚本。

## 能力映射

| 所需能力 | Claude Code | Codex | 无该能力时 |
|---|---|---|---|
| 图片理解 | 使用当前会话的图片读取/视觉能力 | 使用当前会话的图片查看/视觉能力 | 运行 `ocr_text.py`；仍不足则说明限制并询问用户 |
| 已登录浏览器 | 使用配置好的浏览器/MCP 会话 | 使用可用的 in-app browser、Chrome 会话或浏览器工具 | 请求用户提供 Cookie、正文或截图；不得伪造采集结果 |
| 并行/后台任务 | 使用宿主允许的子代理或后台任务 | 仅在当前 Codex 策略允许时使用多代理 | 回退 inline 或顺序执行 |
| 文件写入 | 使用宿主文件工具并遵守项目权限 | 使用补丁/文件工具并遵守沙盒权限 | 在可写目录生成结果；越界前请求授权 |

工具名称可能随宿主和版本变化。以“导航、滚动、DOM 提取、截图、保存文件”等结果为契约，不在核心 SKILL.md 中依赖具体工具名。

## 降级规则

1. L1/L2 脚本不依赖宿主浏览器，应优先执行。
2. L3 必须使用用户已授权的会话，不得绕过登录、验证码或权限边界。
3. 共享浏览器会话必须串行，避免页面跳转和 DOM 状态互相污染。
4. 子代理是性能增强，不是功能依赖；不可用时在主会话完成同一流程。
5. 任何降级都不能跳过归档纯净度、去重、frontmatter 和写入前硬门禁。
